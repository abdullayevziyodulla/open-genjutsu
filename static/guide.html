QUICK START

A new character. The same performance.

Open Genjutsu runs on your computer. Hosted inference is paid through your own API accounts.

1. Connect your accounts

Open API settings. Add Replicate for video preparation, then choose a generation provider. Oxen also needs its key and an existing private namespace/repository for inputs. Saving keys does not check your balance or submit a model call.

2. Prepare and review

Upload a 4–30 second video. Prepare creates motion guidance and may use Replicate credits. Watch the entire prepared clip before approving. Check the mask, hands, hair, clothing and cuts. Use advanced settings only when needed.

3. Replace and generate

Add a character reference and describe the replacement. The optional second character is a different person. Review the exact request and estimate, then generate. The model's quality and billing rules still apply.

4. Download your result

The result keeps the full original soundtrack. You can return to saved jobs from the library. HD is a separate billed action. Failed or uncertain requests are never silently retried.
