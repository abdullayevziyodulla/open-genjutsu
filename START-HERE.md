# Start Open Genjutsu

See README.md for installation and the three-stage studio flow. Start-Open-Genjutsu.cmd launches the local Windows app. Existing Start-Genjustsu.cmd remains a compatibility shortcut in this installation.

Set up your own Replicate preparation token, selected generation key and private Oxen repository in API settings. Saving credentials does not run models or verify balance.
